# Hi, I'm Amauri Champeaux 👋

I'm an independent developer based in Béziers, France. I create and maintain tools for web consent management and WordPress mobile apps.

## 🍋 tarteaucitron.js & tarteaucitron.io

I'm the creator and maintainer of **tarteaucitron.js**, an open-source JavaScript cookie consent manager that helps website owners implement GDPR / RGPD consent controls.

The library provides a customizable cookie banner, service-level consent preferences and integrations with third-party services, including Google Consent Mode v2.

**tarteaucitron.io Pro** adds automatic detection of supported services, an online configuration dashboard and consent statistics.

[Source code](https://github.com/AmauriC/tarteaucitron.js) · [Website](https://tarteaucitron.io/) · [Installation guide](https://tarteaucitron.io/en/free-installation-open-source/)

## 📱 WPMobile.App

I also created **WPMobile.App**, a tool that turns WordPress websites into Android and iOS mobile apps.

Configure your app from WordPress, customize its branding and send push notifications. Preview your app before purchasing a lifetime license, with no WPMobile.App subscription.

[Website](https://wpmobile.app/en/) · [WordPress plugin](https://wordpress.org/plugins/wpappninja/)
